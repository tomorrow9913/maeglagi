Mark

로고와 워드마크

아래로 흩어진 두 가닥이 위에서 하나의 고리로 감기는 실타래입니다. 제품이 하는 일을 그대로 형태로 옮긴 것이라 가닥 수나 교차 위치를 바꾸지 않습니다.

워드마크 — 심볼 + 맥락이

맥락이 text-sm · 최소
맥락이 text-lg
맥락이 text-2xl

규칙

  • 심볼은 글자 크기의 1.15배로 고정 — text-sm, text-lg만 바꾸면 비율이 유지됩니다.
  • 심볼 색은 currentColor. 기본 text-primary, 브랜드 색 위에서만 text-card.
  • 최소 크기 — 심볼 16px, 워드마크 text-sm. 더 작아지면 심볼만 씁니다.
  • 회전, 그림자, 그라디언트, 단색 외 채우기 금지
  • 워드마크에 부제·영문 병기·자간 변경 금지

Character

맥락이 캐릭터

실타래 몸통에서 실 한 가닥이 풀려 나옵니다. 심볼과 같은 은유를 쓰되 역할을 나눕니다 — 심볼은 제품을 가리키는 마크, 캐릭터는 사용자에게 말을 거는 화자입니다. 포즈는 두 가지뿐이고 표정을 새로 만들지 않습니다.

default

답변 화자 아바타

눈을 뜨고 정면. 맥락이가 말하고 있는 자리에 씁니다. 크기는 size-8.

resting

빈 상태, 답변 대기

눈을 감고 실이 길게 풀립니다. 기다리는 자리에만 씁니다. 빈 상태 size-9, 화면 중앙 안내 size-12.

색은 text-primary 하나만 씁니다. 캐릭터 안에서 색을 두 개 이상 쓰지 않습니다.

애니메이션은 캐릭터 자체에 넣지 않고 필요하면 쓰는 쪽에서 감쌉니다. 캐릭터가 조용한 동료로 읽혀야 하기 때문입니다.

Color

색 토큰

sage green(브랜드) + warm buff(배경) 조합입니다. 회의록과 문서를 오래 읽는 화면이라 순백 대신 따뜻한 종이 톤을 깔고, 강조는 채도가 낮은 초록 하나로만 줍니다. 대비는 배경 #f5f3ee 기준입니다.

색 표기는 HSL이 아니라 oklch입니다. Tailwind v4와 shadcn 기본 테마가 oklch를 쓰고, 밝기를 고정한 채 색상만 바꿀 때 HSL보다 결과가 예측 가능해서입니다.

디자인 도구에서 값을 옮겨올 때만 위 표의 hex를 쓰고, 코드에는 oklch를 넣습니다. 값의 원본은 frontend/src/app/globals.css의 :root입니다.

Graph

Voice

화자와 말투

화면 위치가 아니라 문장의 성격으로 화자를 정합니다. 같은 카드 안에서도 제목은 시스템, 설명은 맥락이가 될 수 있습니다. 맥락이는 발랄한 마스코트가 아니라 조용하고 성실한 동료입니다.

문장의 성격화자어미예
다음에 뭘 하면 되는지 권함 맥락이 해요체 회의나 문서를 올리면 결정과 이벤트가 여기에 쌓여요.
맥락이가 지금 하는 일 맥락이 해요체 관련 회의와 문서를 찾아보고 있어요
사실·상태·결과를 알림 시스템 합니다체, 무주어 API key를 저장했습니다.
오류와 실패 시스템 합니다체, 무주어 업로드에 실패했습니다.
버튼·라벨·필드 시스템 명사형 다시 시도 / 대화 지우기
AI 답변 본문 맥락이 합니다체 …hybrid retrieval을 채택했습니다[1].

답변 본문만 맥락이가 말하면서도 합니다체를 씁니다. 결정과 근거를 다루는 문장이라 꾸미면 신뢰가 떨어지기 때문입니다.

금지: 느낌표와 이모지, 과장과 자화자찬, 추측을 단정으로 말하기, 사과 반복, 잠시만 기다려주세요 같은 빈 대기 문구, 근거 없는 시간 약속. 자기 호칭은 맥락이이며 저, 제가는 쓰지 않습니다.
